### Added
- With pi's ovis-model extension, the composer's model pill opens a menu of pi's scoped models and
  a thinking slider with the levels the model takes; a choice switches pi through its own API while
  it is idle. The extension also gives the context ring pi's own window, for providers no catalog
  on disk names (claude-bridge). Each model in the menu carries its maker's mark (Claude, Codex,
  Gemini, Grok, Kimi, Qwen), read from its name whatever provider carries it.
- Settings → Context circle hides the ring.

### Changed
- The context ring stands before the model pill and a tap shows its numbers in a bubble, on a phone
  too. pi's has no Compact button.
- The model pill no longer draws the agent's mark: the header names the agent.
- The Chat, Terminal and Computer switch in the header is icons only at every width; each
  button keeps its name for screen readers and its tooltip.
- On a phone or touch screen, the header names the pane's git branch on a dim line under its title, lined up with the name,
  where the composer has no folder-and-branch strip. A tap shows a long name whole.
