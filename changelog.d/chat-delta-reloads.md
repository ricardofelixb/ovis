### Changed
- A chat reads again only the turns that changed: it names the newest page it holds, and the PC
  answers with the turns after the run the two share. A long chat on a slow link reads a few KB
  when a message lands instead of its whole newest page, so a sent message shows sooner and a
  phone downloads far less while an agent works. A page the PC no longer has is read whole.

### Fixed
- A folded work block no longer opens for a moment as the agent finishes before its last words
  are drawn.
